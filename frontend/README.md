# Frontend

Nuxt 4 SPA (`ssr: false`) with Nuxt UI and `nuxt-auth-sanctum`, talking to the Laravel API.

```sh
npm install
npm run dev        # http://localhost:3000
npm run generate   # static build in .output/public
```

Set `NUXT_PUBLIC_API_BASE_URL` to point at a different API (default `http://localhost:8000`).
